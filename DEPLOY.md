# Выкладка NovaLab на Railway

> Основной сервер — VPS, см. **DEPLOY-VPS.md**. Railway остаётся тестовой площадкой.
> Пакеты тем на Railway: файлы билдов пишутся в `./data` и **пропадают при следующей выкладке**,
> если не подключить Railway Volume и не задать `DATA_DIR=/data`. Описания тем в базе при этом сохраняются.

Сайт: **https://web-production-4125d.up.railway.app**
Проект Railway: `novalab` (сервисы `web` — сайт, `Postgres` — база).

## Как устроено

- `npm run build` → `prisma generate && next build`
- `npm run start` → `prisma migrate deploy && prisma db seed && next start`
  — при каждом запуске применяются новые миграции и обновляется библиотека уроков (сид безопасно запускать повторно,
  уроки учителей и результаты учеников он не трогает).
- Unity WebGL-билды лежат в `public/modules/<id модуля>/` и загружаются вместе с сайтом.
- Настройки сборки и запуска — `railway.json` (Railway поддерживает этот формат до 01.12.2026, потом —
  `railway config migrate`).

Переменные сервиса `web`:

| Переменная | Значение |
|---|---|
| `DATABASE_URL` | `${{Postgres.DATABASE_URL}}` — ссылка на базу Railway |
| `AUTH_SECRET` | случайная строка (сгенерирована при настройке, хранится только в Railway) |
| `AUTH_TRUST_HOST` | `true` |
| `ADMIN_EMAIL` | почта администратора панели `/admin` |
| `ADMIN_PASSWORD` | пароль администратора (от 10 символов) — задаёт владелец проекта сам |
| `ADMIN_NAME` | необязательно: имя администратора |

## Панель администратора

Адрес: `/admin` (вход — `/admin/login`). Там собраны все оценки уроков: отзывы учеников (1–10 и комментарии),
анкеты учителей, сводка по урокам и выгрузка CSV.

Как она отделена от сайта:

- администраторы хранятся в отдельной таблице `Admin`, а не среди учителей и учеников — зарегистрироваться
  администратором через сайт нельзя, а пароль учителя не открывает панель;
- вход через отдельный провайдер `admin` (`auth.ts`), в сессии роль `ADMIN`;
- у панели свой каркас (`app/admin`), каждая страница и API `/api/admin/*` проверяют `adminSession()`;
- администратор не имеет доступа к кабинетам учителей и учеников (`teacherSession()` пускает только `TEACHER`);
- страницы панели закрыты от поисковиков (`robots: noindex`).

Создать администратора на Railway: добавить переменные `ADMIN_EMAIL` и `ADMIN_PASSWORD` в сервис `web`
(Variables) — при следующем запуске сид создаст администратора или обновит ему пароль.
Локально: `npm run admin:create -- почта "Имя"` (пароль из `ADMIN_PASSWORD` или сгенерируется).

## Обновить сайт

Из папки `physlab` (Railway CLI уже привязан к проекту):

```bash
npx @railway/cli up --service web --ci
```

Новый Unity-билд: `npm run unity:import -- "<папка билда>" <id модуля>`, затем команда выше.

## Полезное

```bash
npx @railway/cli logs --service web
```
```bash
npx @railway/cli open
```
