# Пакеты тем NovaLab

Одна тема учебника = один **пакет** — ZIP-архив со всеми её модулями: конспект, графики, симуляция, практика, квиз, карточки.
Администратор загружает пакет в панели (`/admin/packages`) — тема сразу появляется в библиотеке учителей и в «Моей
лаборатории» учеников. **Пересобирать и перезапускать сайт не нужно.**

Самый простой способ сделать новый пакет — скачать любой готовый («Скачать пакет» у темы в панели) и поменять его.

## Состав архива

```
novalab-topic.json            ← описание темы и модулей (обязательно, в корне архива)
builds/density-sim/           ← Unity WebGL-билд симуляции: index.html + Build/ + TemplateData/
builds/density-practice/      ← билд практики (если практика сделана в Unity)
```

## novalab-topic.json

```json
{
  "format": "novalab-topic@1",
  "version": "1.0.0",
  "grade": 7,
  "section": "Плотность",
  "paragraph": "§ 12",
  "topic": "Плотность вещества и единицы измерения плотности. Расчёт плотности",
  "modules": [
    {
      "id": "density-sim",
      "type": "simulation",
      "title": "Симуляция: плотность тел",
      "description": "Взвешиваем тела и измеряем объём",
      "build": "builds/density-sim",
      "configSchema": { "material": "aluminium" },
      "content": { "goal": "…", "scene": "…", "controls": [], "observe": ["…"], "tasks": ["…"] }
    },
    { "id": "density-summary", "type": "summary", "title": "Конспект: плотность", "content": { "blocks": [{ "kind": "p", "text": "…" }] } },
    { "id": "density-quiz", "type": "quiz", "title": "Квиз: плотность", "content": { "questions": [ … ] } }
  ]
}
```

| Поле | Что это |
|---|---|
| `grade` | класс (7–11) — должен быть в программе |
| `section` | глава учебника, точно как в библиотеке; если такой нет — будет создана в конце |
| `topic`, `paragraph` | тема и её номер («§ 12», «Лаб. № 3»); если тема уже есть — пакет её обновит |
| `modules[].id` | постоянный id: латиница, цифры, дефис. По нему обновляется модуль и сохраняются уроки учителей |
| `modules[].type` | `simulation`, `summary`, `graph`, `practice`, `quiz`, `matching` |
| `modules[].build` | папка Unity-билда в архиве (только для `simulation` и `practice`; у симуляции обязательна) |
| `modules[].content` | содержимое модуля — те же поля, что в `lib/modules/types.ts` и в `content/topics/*.ts` |

## Что проверяется при загрузке

- описание по формату, содержимое каждого модуля подходит к его типу, id не повторяются;
- у симуляции есть билд, а в папке билда — `index.html`;
- id модуля не занят модулем **другой** темы;
- у практики «составь и реши» есть проверщик ответов на сервере (`content.topic`: сейчас `speed`, `archimedes`).
  Ответ ученика сервер решает заново сам, поэтому для практики по **новой** физической теме нужен проверщик
  в `lib/practice/` — это единственная часть, которая требует обновления сайта. Конспект, графики, квиз, карточки
  и симуляция загружаются без обновления;
- пути внутри архива не выходят за папку билда; архив — до 500 МБ и 2000 файлов.

Если что-то не так — пакет не загружается целиком, панель показывает список ошибок. Уже загруженное не трогается.

## Повторная загрузка

Пакет с той же темой обновляет её модули (по `id`): уроки учителей, которые собраны из этих модулей, и результаты
учеников сохраняются. Новый билд заменяет старый целиком. Модули, которых нет в новом пакете, не удаляются.

## Удаление пакета

В списке «Темы с модулями» у каждой темы — и загруженной пакетом, и встроенной — есть кнопка «Удалить».
Окно показывает, что затронет удаление, и код из 6 цифр, который нужно ввести (код выдаёт сервер, действует
10–20 минут и подходит только к этой теме — случайно удалить нельзя ни кнопкой, ни запросом к API).

Что происходит:
- удаляются все модули темы, их блоки в уроках учителей (сами уроки остаются) и результаты учеников по этим модулям;
- файлы билдов пакета удаляются с диска;
- тема, **созданная пакетом**, исчезает из учебника вместе с заметками учеников в «Моей лаборатории»; глава,
  созданная пакетом, — если в ней не осталось тем и её нет в планах четвертей;
- тема **из программы учебника** остаётся в оглавлении без модулей; её встроенные модули записываются в
  `RemovedModule`, и сид больше не создаёт их при запуске;
- в истории загрузок пакет помечается «удалён».

Отменить удаление нельзя. Перед удалением можно нажать «Скачать пакет»: загрузив его снова, вы вернёте модули
(в том числе встроенные — отметка `RemovedModule` при загрузке снимается), но не результаты учеников.

## Где лежат файлы

Билды пакетов хранятся в `DATA_DIR/modules/<id>/` (на VPS — том Docker `data`) вместе со сжатыми копиями `.br`
и отдаются по адресу `/content/modules/<id>/index.html` — на VPS напрямую через Caddy.
На Railway без подключённого тома (Volume) загруженные билды пропадут при следующей выкладке — для пакетов
нужен VPS или Railway Volume с `DATA_DIR=/data`.
